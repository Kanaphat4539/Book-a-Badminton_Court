# 🏸 KMITL Badminton - Frontend Tech Stack

เอกสารนี้รวบรวมข้อมูลสรุปเกี่ยวกับเครื่องมือ, เฟรมเวิร์ก, และภาษาที่ใช้ในการพัฒนาระบบ Frontend ของโปรเจกต์ KMITL Badminton

## 1. ภาษาที่ใช้ (Programming Language)
*   **TypeScript (`.ts`, `.tsx`)**: ระบบนี้เขียนด้วย TypeScript ทั้งหมด เพื่อลดข้อผิดพลาดจากการเขียนโค้ด (Type Safety) และช่วยให้บำรุงรักษาระบบ (Maintain) ในระยะยาวได้ง่ายและมีเสถียรภาพมากกว่า JavaScript แบบดั้งเดิม

## 2. โครงสร้างและเฟรมเวิร์กหลัก (Core Framework)
*   **Next.js (v16.2.10)**: เป็น React Framework ระดับโลกที่จัดการเรื่องการทำระบบ Routing ในตัวผ่านโฟลเดอร์ `app/` และช่วยเพิ่มประสิทธิภาพด้านความเร็วในการโหลดหน้าเว็บ
*   **React (v19)**: เป็นไลบรารีเบื้องหลังตัวล่าสุดของ Next.js ที่จัดการเรื่องการวาด UI (Component-based)

## 3. เครื่องมือออกแบบและจัดการความสวยงาม (Styling & Design)
*   **Tailwind CSS (v4)**: เครื่องมือ (CSS Framework) หลักสำหรับจัดการดีไซน์ทั้งหมดในโปรเจกต์ โดยใช้เวอร์ชัน 4 ซึ่งเป็นเวอร์ชันใหม่ที่ประมวลผลเร็วขึ้น
*   **Shadcn/UI & Base UI**: โครงสร้างพื้นฐานของ UI Component ที่ใช้งานง่าย หน้าตาสวยงาม และปรับแต่งได้ยืดหยุ่น
*   **next-themes**: ตัวช่วยจัดการสำหรับทำระบบเปิด/ปิด โหมดมืดและสว่าง (Dark / Light Mode)
*   **tw-animate-css & tsparticles**: ไลบรารีสำหรับใส่ลูกเล่นแอนิเมชันให้ดูพรีเมียมและไหลลื่น เช่น เอฟเฟ็กต์พื้นหลัง หรือพาร์ติเคิล

## 4. เครื่องมือจัดการระบบเครือข่ายและข้อมูล (Networking & Data)
*   **Axios**: ไลบรารีหลักที่ระบบใช้สำหรับเชื่อมต่อและรับส่งข้อมูลผ่าน API กับ Backend
*   **date-fns**: ไลบรารีที่มีประสิทธิภาพในการจัดการ แปลง และคำนวณวัน-เวลาให้ออกมาแสดงผลได้อย่างถูกต้อง

## 5. เครื่องมือตัวช่วยอื่นๆ ในโปรเจกต์ (Utilities & Plugins)
*   **html5-qrcode**: เครื่องมือสำหรับเปิดกล้องและอ่านค่า QR Code เพื่อใช้ในการ Check-in เข้าสนาม
*   **react-qr-code**: ใช้สำหรับ Generate รูป QR Code ให้ผู้ใช้นำไปสแกน 
*   **Sonner**: ระบบแจ้งเตือน (Toast Notification) ที่สวยงามเวลาผู้ใช้ทำงานสำเร็จหรือเกิดข้อผิดพลาด
*   **Lucide React**: ชุดไอคอนมาตรฐานที่มีสไตล์เรียบหรูและมินิมอล 

---
**สรุป**: ระบบ Frontend ถูกพัฒนาด้วยสแต็กยุคใหม่คือ **Next.js + TypeScript + Tailwind CSS** ซึ่งเป็น "Modern Stack" มาตรฐานองค์กรชั้นนำ รองรับการทำงานแบบ Responsive เต็มรูปแบบและทำงานได้อย่างรวดเร็ว
